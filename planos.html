Perguntas Comuns

Preciso instalar algum programa?

Não, se você trabalha no tablet do chão de fábrica. O sistema roda direto no navegador. Para gestores de escritório, existe também o AriLine Desktop — um app que instala no Windows ou Linux e sincroniza em tempo real com o mesmo banco de dados, sem precisar abrir navegador.

Web e Desktop mostram os mesmos dados?

Sim. Ambas as interfaces conectam ao mesmo banco de dados em nuvem. Um apontamento feito pelo operador no tablet aparece imediatamente no desktop do supervisor. Não há sincronização manual nem conflito de dados.

Preciso trocar de ERP?

Não. A AriLine atua focada na fábrica e se integra ao seu ERP atual (Totvs, SAP, Sankhya) para puxar ordens de produção e devolver apontamentos.

E se a internet cair?

Nossa arquitetura permite apontamentos offline temporários nos tablets da fábrica. Assim que a rede volta, os dados sincronizam automaticamente — tanto na versão web quanto no desktop.

Como é o suporte?

Falamos pelo WhatsApp direto com os gerentes de produção. Sem sistema de tickets lentos. O foco é não parar a fábrica.

O que é a implantação incluída?

Nós mapeamos seu processo, importamos seus produtos, configuramos os apontamentos e treinamos sua equipe. Você só começa a pagar a mensalidade quando o sistema estiver rodando.
